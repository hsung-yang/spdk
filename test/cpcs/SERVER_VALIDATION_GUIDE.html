CPCS Server Validation Guide

Step-by-step server runbook for the unified CPCS orchestrator. Use this to execute claim-coverage validation on loopback or split initiator/target deployments.

Entrypoint: spdk/test/cpcs/cpcs_experiments.py Mode: Loopback / Split Required target: under_supported_claims=[]

Step 0. Choose Topology

Use one of the two supported deployment models:

  • Loopback: initiator and target are the same host.
  • Split: initiator is local orchestrator, target is remote via SSH.
Hard contract: roles.initiator must be mode: local.

Step 1. Install Prerequisites

  • python3, python3-yaml
  • Build tools (make, compiler)
  • Passwordless sudo strongly recommended
  • Same SPDK repo path available on all hosts in your inventory
sudo apt-get install -y python3-yaml

Step 2. Set Inventory

Start from examples:

  • Split: spdk/test/cpcs/examples/inventory_split.yaml
  • Loopback: spdk/test/cpcs/examples/inventory_loopback.yaml

Required fields to verify

  • hosts.<name>.repo_path
  • roles.initiator, roles.target
  • nvmeof.trtype, traddr, trsvcid, nqn, hostnqn

Recommended defaults (physical backends)

  • nvmeof.pcie_bdf
  • nvmeof.dataset_bdev
  • nvmeof.backing_bdev

Optional runtime overrides

  • runtime.target_core_mask
  • runtime.initiator_passthru_lcores
  • runtime.vector_prefill_workers

Step 3. Preflight Variables

export REPO=/path/to/spdk
export INV=$REPO/test/cpcs/examples/inventory_split.yaml    # or inventory_loopback.yaml
export ART_ROOT=/tmp/cpcs_server_eval_$(date +%Y%m%d_%H%M%S)
export RUNLOG=$ART_ROOT/run.log
export TLOG=/var/log/spdk.log
mkdir -p "$ART_ROOT"
cd "$REPO"

Split-mode connectivity check

ssh <target-user>@<target-host> 'hostname; test -d /path/to/spdk && echo repo_ok'

5.6 ann-search (ANN required)

Start OpenSearch:

bash ./experiments/real_apps/opensearch/bringup_opensearch.sh

Generate synthetic ANN docs/queries:

python3 - <<'PY'
import json, os, pathlib
root = pathlib.Path(os.environ["ART_ROOT"]) / "ann_prep"
root.mkdir(parents=True, exist_ok=True)
docs = root / "documents.jsonl"
queries = root / "queries_real.json"
dim = 16
n_docs = 1024
n_queries = 128
with docs.open("w", encoding="utf-8") as f:
    for i in range(n_docs):
        base = i + 1
        vec = [round(((base * (j + 3)) % 97) / 97.0 + 1e-3, 6) for j in range(dim)]
        row = {
            "id": i,
            "vector": vec,
            "payload": {
                "doc_id": i,
                "category_id": i % 8,
                "flags": i % 4,
                "region_id": i % 16,
                "price": float((i % 100) + 1),
                "timestamp_bucket": 1700000000 + i,
                "vector_index": i,
            },
        }
        f.write(json.dumps(row, separators=(",", ":")) + "\\n")
query_rows = []
for q in range(n_queries):
    base = q + 1
    vec = [round(((base * (j + 3)) % 97) / 97.0 + 1e-3, 6) for j in range(dim)]
    query_rows.append({
        "query_id": q,
        "outer_request_id": q,
        "round": 0,
        "metric": "cosine",
        "k": 10,
        "vector": vec,
        "filters": [{"op": "eq", "field": "flags", "value": q % 4}],
        "target_selectivity_hint": f"flags_eq_{q % 4}",
    })
queries.write_text(json.dumps({"version": 1, "query_count": len(query_rows), "queries": query_rows}, indent=2), encoding="utf-8")
print("wrote", docs)
print("wrote", queries)
PY

Run ANN scenario:

sudo -E python3 ./test/cpcs/cpcs_experiments.py \
  --inventory "$INV" --artifacts-root "$ART_ROOT" --target-log "$TLOG" \
  ann-search -- \
  --system opensearch \
  --host http://127.0.0.1:9200 \
  --index cpcs_server_ann \
  --docs-jsonl "$ART_ROOT/ann_prep/documents.jsonl" \
  --queries-json "$ART_ROOT/ann_prep/queries_real.json" \
  --load-index --recreate-index \
  --top-k 10 --limit-queries 64 \
  --recall-threshold 0.90 --overlap-threshold 0.80 \
  --no-configure-index-flag

Step 8. Failure Triage

SymptomAction
roles.initiator must use mode=local Fix inventory so initiator host uses mode: local.
sudo -n failures on target Enable passwordless sudo, or set use_sudo: false and manage runtime manually.
Transport baseline max-I/O size errors Reduce --host-read-chunk-mb (e.g., 0.125).
OpenSearch rejects index.knn.ndp.cpcs.enabled Use --no-configure-index-flag for ann-search and realapp-*.
capacity-gap full-fit allocation failure Increase RAM/hugepages. Do not relax full-fit scenario contracts.

Fast smoke path

  1. prepare --skip-build
  2. transport-bottleneck (small dataset)
  3. lease-correctness
  4. ann-search --limit-queries 8
