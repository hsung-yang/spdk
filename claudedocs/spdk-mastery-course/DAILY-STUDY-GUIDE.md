**Daily Schedule**:
```

Saturday: 2 hours hands-on practice

```

**Breakdown**:
- **Weeks 1-3** (Stage 1): 1 hour/day reading + diagrams

```

- 00:00-00:40: Read module content

- 01:00-01:40: Type out code examples

```


## 🎓 Tips for Efficiency

### Maximize Your Study Time

1. **Remove Distractions**
   - Close unnecessary apps
   - Dedicated study space
   - Phone on silent

2. **Active Learning**
   - Type out code examples
   - Draw diagrams by hand
   - Explain concepts aloud

3. **Spaced Repetition**
   - Review previous week on Sunday
   - Revisit difficult concepts
   - Connect new to old material

4. **Hands-On Practice**
   - Don't just read code
   - Type and run every example
   - Modify and experiment

5. **Take Breaks**
   - 25-minute study sessions (Pomodoro)
   - 5-minute breaks
   - Longer break after 2 hours
