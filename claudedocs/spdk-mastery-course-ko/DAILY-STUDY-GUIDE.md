## 📅 학습 일정 옵션

### 옵션 1: 하루 1시간 (여유로운 페이스)

**일정**: ~5-6개월

**일일 스케줄**:
```
월-금: 1시간 학습
토요일: 2시간 실습
일요일: 휴식 또는 복습

주간 총계: ~7시간
```

**세부 계획**:
- **1-3주차** (스테이지 1): 하루 1시간 읽기 + 다이어그램
  - 1일차: 모듈 01 (2시간 → 이틀에 나누어)
  - 3일차: 모듈 02 (2시간 → 이틀에 나누어)
  - 주말: 복습 및 개념 실습

- **4-10주차** (스테이지 2): 하루 1시간 학습 + 코딩
  - 평일: 모듈 내용 읽기
  - 주말: 예제 코딩

- **11-24주차** (스테이지 3): 하루 1시간 학습 + 실습
  - 관심 있는 특정 주제에 집중
  - 실제 프로젝트 구축

**장점**: 지속 가능, 부담이 적음
**단점**: 시간이 더 걸림, 좋은 기억력 필요

## 🎓 효율성을 위한 팁

### 학습 시간 극대화

1. **방해 요소 제거**
   - 불필요한 앱 닫기
   - 전용 학습 공간
   - 휴대폰 무음 모드

2. **능동적 학습**
   - 코드 예제 직접 타이핑
   - 다이어그램 손으로 그리기
   - 개념을 소리 내어 설명하기

3. **간격 반복(Spaced Repetition)**
   - 일요일에 이전 주 복습
   - 어려운 개념 다시 방문
   - 새로운 내용을 이전 내용과 연결

4. **실습 위주**
   - 코드를 단순히 읽기만 하지 않기
   - 모든 예제를 타이핑하고 실행
   - 수정하고 실험하기

5. **휴식 취하기**
   - 25분 학습 세션 (포모도로 기법)
   - 5분 휴식
   - 2시간 후 더 긴 휴식
